# Rooted In Rhythm

Static rebuild of rootedinrhythm.co (Squarespace). Same copy, links and look (black / teal / orange, Bellefair + Source Sans),
with a consistent gutter and 1180px content measure.

    python3 tools/build.py    # regenerates index.html, about.html, sponsor-us.html

Pages: `/` (Home), `/about`, `/sponsor-us`. Images in `img/` (WebP), fonts self-hosted in `fonts/`.
Footer links back to the parent platform, Breaks In The Simulation (`BITS` in `tools/build.py`).
